Life Dashboard

A personal, local-first desktop app.

Life Dashboard is a Windows desktop app for one person to plan their life in one place: tasks, routines, calendar, health, goals, and personal finances. It is a personal project, not a commercial service, and is not offered to the public.

How it works

  • Runs on your own computer. All data is stored in an encrypted database on the user's machine. There is no Life Dashboard server and no account to create.
  • Works only while open. The app syncs and does its work only while its window is open. Nothing runs in the background after it closes.
  • Google Calendar is read-only. The app reads events from the calendars the user picks so they can show next to tasks and count toward the day's free time. It never creates, changes, or deletes calendar events.

Google Calendar access

The app asks for one Google permission, https://www.googleapis.com/auth/calendar.readonly, which lets it view calendar events. The data stays on the user's computer. The Privacy Policy explains exactly what is read, where it is kept, and how to remove it.
